QSR value wars. Competitors with leaner flows. Data confirmed: too many taps, too many screens.

### Research & The Loyalist Problem

"Loyalists" — users who adapted to inefficiency and confused familiarity with quality. Key stakeholder also fell into this camp (original build owner).

### Three Pockets of Change

**Location**
- Problem: Too many pre-menu decisions
- Solution: Defaulting logic based on recent preferences; streamlined new user setup
- Impact: Removed 5 taps before ordering even began

**Menu**
- Problem: Combo building was tedious; each modification felt like its own journey
- Solution: Consolidated customization, smarter defaults, shorter path to bag
- Impact: Dramatic reduction in interactions per item

**Checkout**
- Problem: Overloaded bag screen; everything crammed together
- Solution: Split into two screens — order verification first, payment/logistics second
- Impact: Clearer flow, fewer errors, faster completion

### Navigating Resistance
Built trust with Director of Product as executive advocate. Resistant stakeholder eventually won over by user data.

### The Opportunity
Modernize digital ecosystem. Serve diverse audience. Reinforce brand equity in crowded higher ed landscape. Capture spirit of campus life emotionally.

### Design Direction & IA
100+ pages, six primary navigation trees. Template-based approach over page-by-page design.

Key architectural decisions:
1. **Mega-navigation** — Reduced cognitive load while accommodating complex hierarchy
2. **Global utility header** — Quick-access for ~80% of homepage traffic intent
3. **College-specific navigation instances** — University-wide consistency + college-level autonomy

Moderated usability testing across all persona groups. Key outcomes: users praised IA clarity; navigation tested intuitive across segments; only minor visual refinements needed.

Transformation: dated maze → modern intuitive platform.

- Proactive stakeholder engagement as critical as design quality
- Accessibility as design opportunity, not compliance checkbox

## VISUAL DESIGN SYSTEM
> For Claude Code: use this section as the primary design brief. All decisions below are intentional. Do not default to generic patterns.

### INSPIRATION SOURCES

Two reference portfolios were analyzed and blended for this design direction:

**From fiordaliso.io:**
- Dark near-black foundation with a single accent color
- Structured case study cards with metrics front-and-center (the x2, x6, +30% treatment)
- Small colored eyebrow label + large white heading pattern for section intros
- Alternating card layouts (image left/right) that create rhythm without grid monotony
- Clean, scannable section organization — nothing fighting for attention

**From aaronjames.design:**
- Typographic confidence — hero headline pushes to viewport edge, brutally large
- Warm amber/yellow accent against near-black (retained and warmed to `#E8A020` — fits Cody's personality better than the original aggressive yellow)
- Vertical rotated sidebar nav as a craft detail that signals intentionality
- Editorial pacing — massive whitespace, images allowed to breathe
- Minimal chrome — no decorative nonsense, just type and content

**The blend — specific to Cody:**
- **Accent:** Swapped fiordaliso's blue → warm amber `#E8A020`. fiordaliso's blue is clean but cold. Aaron James's yellow is warm but aggressive. Amber splits the difference — confident, warm, editorial.
- **Cards:** Kept fiordaliso's metric-forward card structure because Cody's work has real numbers (70% reduction, 45 outcomes). That data deserves a display system.
- **Typography:** Syne + DM Sans instead of either reference site's fonts. Syne has the same editorial weight as Aaron James's display type but feels more designed, less default.
- **Hero:** No hero image. Aaron James's pure-type hero signals creative confidence. The current site's generic Unsplash stock photo in the hero is gone in the redesign.
- **Result:** A portfolio that feels like the work of someone about to become a Creative Director — opinionated, sparse, confident — while still being scannable and metric-forward enough for a product-minded recruiter.

### COLOR PALETTE

```css
/* Core */
--color-bg:          #0D0D0D;   /* Near-black — deeper than both refs, more editorial */
--color-surface:     #161616;   /* Card backgrounds, elevated surfaces */
--color-surface-alt: #1E1E1E;   /* Hover states, subtle dividers */
--color-border:      #2A2A2A;   /* Hairline borders */

/* Text */
--color-text-primary:   #F2F2F2;  /* Headlines, primary body */
--color-text-secondary: #8A8A8A;  /* Captions, metadata, eyebrow labels */
--color-text-muted:     #555555;  /* Timestamps, footnotes */

/* Accent — the single color decision that defines the personality */
--color-accent:         #E8A020;  /* Warm amber — from Aaron James's yellow, 
                                     warmed slightly. Used SPARINGLY:
                                     active nav item, hover on CTAs, 
                                     metric highlights, link arrows. */
--color-accent-hover:   #F0B030;  /* Lighter on hover */

/* Functional */
--color-tag-bg:         rgba(232, 160, 32, 0.12);  /* Tag/chip backgrounds */
--color-tag-text:       #E8A020;
```

**Accent usage rule for Claude Code:** The amber accent should appear on-screen no more than 3–4 times per viewport. It is a signal, not a pattern. Overuse kills it. Primary uses: the arrow/↗ on CTAs, the active nav item, metric numbers on case study cards, and hover states on interactive elements.

### SPACING & LAYOUT

```css
/* Container */
--container-max:    1200px;
--container-pad:    clamp(24px, 5vw, 80px);  /* Horizontal page padding */

/* Section rhythm */
--section-gap:      clamp(80px, 12vw, 160px);  /* Space between major page sections */
--content-gap:      clamp(40px, 6vw, 80px);    /* Space within a section */
--card-gap:         24px;                       /* Gap between case study cards */

```

**Layout approach:** Left-aligned, not centered. Both reference sites use left-aligned type that gives the design intentional weight and avoids the "resume template" centered layout common in portfolios. The hero headline should push to full width or just past the comfortable line length — editorial tension.

- Vertical rotated label on left edge (Aaron James-style): shows current section name on scroll — a subtle typographic detail that signals craft
- Nav items: DM Sans 400, `--text-sm`, `--color-text-secondary` by default, `--color-accent` on active/hover

### CASE STUDY CARDS (Homepage)

**Card anatomy — take the best of both references:**

```
┌─────────────────────────────────────────────────────────┐
│  [Project image — full bleed, right half or top section] │
│                                                           │
│  BRAND NAME          ← --color-accent, --text-xs tracked │
│  Case Study Title    ← --font-display, --text-h2         │
│  One-line descriptor ← DM Sans, --color-text-secondary   │
│                                                           │
│  [Metric]  [Metric]  [Metric]  ← only if available       │
│  70% fewer taps      ← --color-accent on number          │
│                                                           │
│  View Case Study ↗   ← --color-accent arrow              │
└─────────────────────────────────────────────────────────┘
```

- Cards alternate layout: image right / text left, then image left / text right (fiordaliso pattern — creates rhythm without grid monotony)
- Card background: `--color-surface` (#161616), rounded corners `border-radius: 16px`
- On hover: subtle `translateY(-4px)` lift + border brightens to `--color-border` → `#3A3A3A`
- Metrics are shown **only on cards that have them** (Wendy's: 70% reduction; Wegovy: 45 outcomes). Don't manufacture metrics for cards that don't have them.
- Role tag: small pill — `--color-tag-bg` / `--color-tag-text` — shows the role (e.g. "UX Director", "ACD, Product Design")

### CASE STUDY PAGES (Interior)

**Structure:** Near-identical to fiordaliso's case study layout — clean, editorial, image-forward.

- **Hero:** Full-width project image, title overlaid or immediately below. Executive summary (Brand + Role) as a two-column metadata block in `--text-sm` with subtle top border.
- **Body sections:** Max-width prose (~720px) centered in content column. Section headings in `--font-display`. Body in `DM Sans` at `--text-body-lg` with `--leading-loose`.
- **Pull quotes:** Large, `--font-display`, `--text-h2`, `--color-text-primary` — slightly indented. Used for key strategic statements (e.g. "I want to order Wendy's at a red light.").
- **Metrics blocks:** Inline stat callouts — number in `--color-accent`, label in `--color-text-secondary`. Three-column at most.
- **Images:** Full-width or 80% width. Never floated. Let them breathe with `--content-gap` above and below.
- **Section dividers:** Hairline `1px` `--color-border` rule, not decorative — just structural.

### MICRO-INTERACTIONS & MOTION

Keep these subtle — this is a content-forward site, not a motion demo.

- **Page load:** Staggered fade-up on hero elements (eyebrow → headline → subtext → CTAs), 60ms delay between each. Total duration under 600ms.
- **Card hover:** `translateY(-4px)`, `transition: 200ms ease`. Border color shift. No scale.
- **Nav links:** Underline slides in from left on hover — `scaleX` transform on a `::after` pseudo-element.
- **CTA arrows:** `↗` nudges `4px` right and `4px` up on hover, `transition: 150ms ease`.
- **Scroll progress:** Optional — thin amber `1px` line at top of viewport showing scroll depth on case study pages.
- **No parallax.** No scroll-jacking. No cursor trails. The Aaron James site gets away with its motion because it's minimal — copy the restraint, not the animations.

### WHAT TO AVOID

Claude Code should NOT default to any of these:
- ❌ Centered hero layout with text over image
- ❌ Purple, teal, or generic gradient accents
- ❌ Card grid with equal-height rows (use alternating layout instead)
- ❌ Sans-serif body font that's just "clean" with no personality (no Inter, no Roboto)
- ❌ Boxed section backgrounds with heavy drop shadows
- ❌ Animated gradient mesh backgrounds
- ❌ Anything that looks like a Squarespace template (the current site already looks like this — the redesign should feel like a deliberate departure)

### FAMILY THREAD — eanescreative.co

Eanes Creative Co. is a shared site with Cody's wife. Its design language is deliberately different — warm off-white canvas, deep forest green, heritage serif type — and that separation is correct. These are different sites for different audiences.

**The goal is not to match it. The goal is a subtle thread — something a sharp eye might notice without being told.**

Three specific elements are borrowed and translated into codyeanes.com's dark/amber system:

**1. Button shape — sharp rectangle, no border-radius**
eanescreative.co's most distinctive UI element is its filled rectangular CTA button: zero border-radius, all-caps tracked label, arrow suffix. It's the strongest shared DNA candidate because it reads as a design decision, not a color or font.

```css
/* Primary CTA — Eanes family thread */
.btn-primary {
  display: inline-flex;
  align-items: center;
  gap: 12px;
  background-color: var(--color-accent);  /* #E8A020 amber */
  color: #0D0D0D;                         /* dark text on amber */
  padding: 16px 28px;
  border-radius: 0;                       /* NO radius — sharp rectangle */
  font-family: var(--font-body);
  font-size: var(--text-xs);
  font-weight: 600;
  letter-spacing: var(--tracking-wide);
  text-transform: uppercase;
  transition: background-color 150ms ease;
}

.btn-primary::after {
  content: '→';                           /* Straight arrow — eanescreative convention */
  transition: transform 150ms ease;
}

.btn-primary:hover::after {
  transform: translateX(4px);
}

/* Secondary/ghost — same sharp shape, no fill */
.btn-secondary {
  display: inline-flex;
  align-items: center;
  gap: 12px;
  background: transparent;
  color: var(--color-text-primary);
  padding: 15px 27px;
  border: 1px solid var(--color-border);
  border-radius: 0;
  font-family: var(--font-body);
  font-size: var(--text-xs);
  font-weight: 600;
  letter-spacing: var(--tracking-wide);
  text-transform: uppercase;
  transition: border-color 150ms ease, color 150ms ease;
}

.btn-secondary:hover {
  border-color: var(--color-accent);
  color: var(--color-accent);
}
```

**2. Eyebrow label with `——` dash prefix**
eanescreative.co uses `—— SECTION NAME` as its section label pattern. Apply the same on codyeanes.com:
```
—— CASE STUDIES
—— ABOUT
—— PROCESS
```
Rendered in `--text-xs`, `--color-accent`, `--tracking-wide`, uppercase. The double dash is the connecting thread — subtle enough to read as pure craft, visible enough that someone who knows both sites will recognize the family.

**3. Thin vertical scroll indicator**
eanescreative.co uses a thin vertical line with `SCROLL` in small tracked caps on the homepage hero. Carry this forward at center-bottom of the codyeanes.com hero:
- Line: `1px solid var(--color-border)`, ~48px tall, animates a slow downward pulse
- Label: `SCROLL`, `--text-xs`, `--color-text-muted`, `--tracking-wide`, uppercase, above the line

**What was deliberately NOT borrowed:**
- The serif typeface (that's Beth's voice, not Cody's)
- The warm off-white background (the dark editorial theme is the point)
- The forest green (clashes with amber, muddies the palette)
- The overall heritage/craftsman warmth (Cody's site is forward-leaning; eanescreative.co is grounded — different on purpose)

A designer will notice the connection. A recruiter won't. That's the right balance.

### ONE-SENTENCE DESIGN BRIEF

> A near-black, amber-accented editorial portfolio built on Syne and DM Sans — typographically bold where it counts, ruthlessly sparse everywhere else — that reads like the work of someone who's about to become a Creative Director, not someone who's already comfortable where they are.
